## 🔬 Краткое описание выполненных работ

### Лабораторная работа №1: Классификация
**Цель:** Получение и закрепление навыков предобработки данных и применения методов машинного обучения для решения задач классификации.
**Задачи:**
*   Первичный анализ и визуализация данных (гистограммы, диаграммы рассеяния, боксплоты).
*   Очистка данных: удаление неинформативных признаков, обработка пропусков, удаление дубликатов.
*   Построение матрицы корреляций.
*   Обучение и подбор параметров для моделей:
    *   K-ближайших соседей (KNN)
    *   Машина опорных векторов (SVM)
    *   Дерево решений / Случайный лес
*   Оценка качества моделей (precision/recall/f1-score/ROC-AUC) и визуализация (Feature Importance / Дерево решений).

### Лабораторная работа №2: Кластеризация
**Цель:** Получение и закрепление навыков предобработки данных и применения методов машинного обучения для решения задач кластеризации.
**Задачи:**
*   Подготовка данных (масштабирование признаков).
*   Обучение моделей и подбор параметров:
    *   Метод К-средних (K-Means) с использованием метода локтя (Elbow Method) и коэффициента силуэта.
    *   DBSCAN (подбор eps и min_samples).
    *   Иерархическая кластеризация (построение дендрограммы).
*   Оценка моделей: экспертная оценка, сравнение с реальными классами (crosstab), визуализация предсказанных значений.

### Лабораторная работа №3: Регрессия
**Цель:** Получение и закрепление навыков предобработки данных и применения методов машинного обучения для решения задач регрессии.
**Задачи:**
*   Предварительная обработка данных (визуализация значимых признаков, очистка от выбросов и нулевых значений целевой переменной, кодирование категорий).
*   Обучение моделей и подбор параметров (где применимо):
    *   Линейная регрессия (Linear Regression).
    *   Ридж-регрессия (Ridge) с подбором гиперпараметра `alpha` через `GridSearchCV`.
    *   Лассо-регрессия (Lasso) с подбором гиперпараметра `alpha` через `GridSearchCV`.
*   Оценка моделей: вывод метрик (MAE, RMSE, R²), построение графиков «Предсказания vs Реальность», анализ коэффициентов моделей (Feature Importance).

## 📈 Ключевые результаты (Лабораторная работа №3)
В ходе выполнения 3-й лабораторной работы была решена задача предсказания запаса хода электромобиля (`Electric Range`).
*   Была проведена глубокая очистка данных (удаление 35% записей с нулевым запасом хода), что позволило выявить четкую линейную зависимость.
*   Лучший результат показала **Линейная регрессия** (и Ridge с малым `alpha`): **R² ≈ 0.9488**, MAE ≈ 15.68 миль.
*   Применение Lasso-регрессии с высоким `alpha` позволило обнулить 136 из 160 признаков, выявив наиболее значимые (Make_TESLA, Electric Vehicle Type_PHEV).
